# Лабораторна робота №3 — обробка тексту підручника (варіант 1)

Програма на Haskell читає текст підручника з програмування з файлу й розбирає його на
типи **Символ**, **Слово**, **Розділовий знак**, **Лексема**, **Речення**, **Абзац** і **Текст**.
Потім вона **сортує слова за зростанням частки голосних букв**, тобто за відношенням кількості
голосних до загальної кількості букв у слові. У тексті, який формує програма, табуляції й
послідовності пробілів замінено одним пробілом.

## Структура

```
textbook-processor/
├── textbook-processor.cabal
├── app/Main.hs          читання файлу, вивід звіту, збереження result.txt
├── src/
│   ├── Types.hs         типи Symbol, Word, Punctuation, Token, Sentence, Paragraph, Text + клас Render
│   ├── Parser.hs        абзаци → речення → лексеми, нормалізація пробілів
│   └── Analysis.hs      клас HasLetters (частка голосних), сортування
└── data/textbook.txt    тестовий текст (з табуляціями й зайвими пробілами)
```

## Типи

| Тип | Опис |
|---|---|
| `Symbol` | один символ (`newtype Symbol = Symbol Char`) |
| `Word` | слово: послідовність символів, що починається з букви (усередині допускаються цифри, `_`, апостроф і дефіс між буквами: *об'єкт*, *будь-який*) |
| `Punctuation` | розділовий знак: `Period`, `Comma`, `Semicolon`, `Colon`, `Exclamation`, `Question`, `Ellipsis`, `Dash`, дужки, лапки, інші знаки |
| `Token` | лексема: слово, число, розділовий знак або пробіл |
| `Sentence` | речення: список лексем, що закінчується на `.`, `!`, `?` або `...` |
| `Paragraph` | абзац (абзаци розділено порожніми рядками) |
| `Text` | увесь текст |

**Класи типів:**
- `Render` перетворює будь-який із цих типів назад у рядок. Кожна послідовність пробілів,
  табуляцій і переносів рядка всередині абзацу стає однією лексемою `TSpace` і виводиться
  одним пробілом.
- `HasLetters` (екземпляри для `Word` і `Sentence`) визначає `lettersOf`, `letterCount`,
  `vowelCount` і `vowelRatio`. Частка голосних рахується точно, як `Rational`.

**Голосні:** українські *а е є и і ї о у ю я* та англійські *a e i o u y*. Апострофи, дефіси й
цифри до букв не належать і в частці не враховуються.

Сортування стійке (`sortOn`): слова з однаковою часткою голосних лишаються в порядку появи в тексті.

## Запуск

```powershell
cabal build
cabal run textproc                                    # data/textbook.txt -> result.txt
cabal run textproc -- мій_підручник.txt вихід.txt     # свої файли
cabal run textproc -- data/textbook.txt result.txt --unique   # кожне слово один раз
```

Програма виводить:
1. нормалізований текст (абзаци, речення, один пробіл замість табуляцій і пробілів);
2. статистику: кількість абзаців, речень, слів;
3. таблицю слів, відсортованих за зростанням частки голосних (кількість голосних, кількість
   букв, частка десятковим і звичайним дробом).

Той самий звіт зберігається у файл `result.txt` у кодуванні UTF-8.
